## 📋 Descripción

Portafolio web profesional desarrollado con **PHP** y **MySQL** para Guido Bardi. Incluye frontend público, panel de administración completo (CRUD) y API RESTful. Diseño responsive con Bootstrap 5 y sistema de autenticación seguro.

### ✨ Características

- ✅ Frontend público con secciones: Biografía, Habilidades, Tecnologías, Proyectos y Contacto
- ✅ Panel de administración completo (CRUD para todas las secciones)
- ✅ API RESTful con endpoints JSON
- ✅ Sistema de autenticación seguro (password_hash)
- ✅ Protección contra SQL injection (PDO prepared statements)
- ✅ Protección contra XSS (htmlspecialchars)
- ✅ Sistema de CSRF tokens
- ✅ Diseño responsive con Bootstrap 5
- ✅ Animaciones CSS y efectos hover
- ✅ Formulario de contacto funcional
- ✅ Dashboard con estadísticas

## 📦 Requisitos del Sistema

- PHP 7.4 o superior
- MySQL 5.7 o superior
- Servidor web (Apache/Nginx)
- XAMPP / WAMP / MAMP (para desarrollo local)
- Navegador web moderno

## 🛠️ Tecnologías Utilizadas

### Backend
- **PHP 7.4+** - Lógica del servidor
- **MySQL** - Base de datos
- **PDO** - Conexión segura a BD
- **API REST** - Endpoints JSON

### Frontend
- **HTML5** - Estructura
- **CSS3** - Estilos personalizados
- **Bootstrap 5** - Framework CSS
- **JavaScript** - Interactividad
- **AJAX** - Peticiones asíncronas
- **Font Awesome 6** - Iconos
